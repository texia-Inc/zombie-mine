# ドワーフドーザー（Dwarf Dozer）

竜に奪われた10の山を、ドワーフの採掘ギルドが蒸気仕掛けの重機で取り戻す放置系採掘ゲームのプロトタイプです。ブラウザだけで遊べます。

**▶ 遊ぶ: https://texia-inc.github.io/zombie-mine/**

## 遊び方
- ドラッグ（PC は WASD / 矢印キー）で操作、スペースでダッシュ
- 鉱石を炉に押し込んでコインを稼ぎ、床のパッドに乗ってスコップ・エンジン・見習いドワーフ・コンベアを強化
- 門を開けて奥へ進み、出荷場の貨車を満たして蒸気鉄道を王都へ出発させると、その山を奪還
- ワールドマップから10の鉱山と3つの竜の巣（砲台に鉱石を込めてドラゴンを討伐）に挑戦
- クリアで手に入るギルド徽章・竜鱗で永続強化

## 技術メモ
- `index.html` 1ファイル。Three.js r128（cdnjs）と Google Fonts を読み込みます
- 進行はブラウザの localStorage に保存されます

## ローカルで動かす
```bash
python3 -m http.server 8080   # http://localhost:8080
```
